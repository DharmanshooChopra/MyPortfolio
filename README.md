# Dharmanshoo Chopra - Portfolio 🚀

A modern, high-performance portfolio website built to showcase my projects, skills, and experience as a Data Scientist and AI/ML Engineer.

## Tech Stack 🛠️
- **Frontend Framework:** React, TypeScript, Next.js
- **3D & Animations:** ThreeJS, React Three Fiber, WebGL, GSAP
- **Styling:** CSS, Tailwind (optional classes)
- **Tooling:** Vite

## Key Features
- **3D Character Model**: Central interactive visual elements powered by Three.js.
- **Dynamic Projects Showcase**: A fully responsive, single-page carousel displaying complex Data Science, AI, and backend projects.
- **Glassmorphism UI**: Beautiful semi-transparent backgrounds with a robust custom cursor implementation.

## Installation & Setup
1. Clone the repository
2. Install dependencies with `npm install`
3. Start the dev server with `npm run dev`

*(Note: The repository uses some GSAP trial plugins locally for advanced scroll effects).*
